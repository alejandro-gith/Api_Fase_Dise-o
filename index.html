Tacomanda — Documentación de API

Proyecto de gestión de comandas para el restaurante Tacos Angy. Contrato OpenAPI 3.0.3, con 16 operaciones HTTP en 7 categorías.

Estado: fase de diseño. Esta página muestra documentación, no una API activa. Los endpoints no procesan peticiones reales y todavía no existe un servidor ASP.NET Core implementado.

Arquitectura prevista

Angular → peticiones HTTP/JSON con JWT → ASP.NET Core API → Application (CQRS) y Domain → Infrastructure (EF Core) → MySQL.

Alcance

La documentación establece la interfaz prevista entre frontend y backend. La conexión con MySQL, las respuestas HTTP reales y la autorización completa por roles quedan para la implementación.
